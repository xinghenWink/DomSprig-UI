DomSprig-UI 需要构建工具吗？
不需要。引入 CSS 与 JS 文件即可使用，组件以源码分发，可直接复制到项目里修改。
支持哪些浏览器？
Chrome / Edge 120+、Safari 17+、Firefox 120+。依赖 light-dark() 与 color-mix() 等现代 CSS。
如何切换暗色主题？
在 <html> 上设置 data-theme="dark"，或调用 Nova.theme.toggle()；不设置时跟随系统。

如何开具发票？

订单完成后，在「我的订单 → 订单详情」点击「申请发票」，电子发票会在 1 个工作日内发送到你的邮箱。

退款多久到账？
原路退回：微信、支付宝即时到账，银行卡 1–3 个工作日。
可以修改绑定的手机号吗？
可以。在「账号安全 → 手机号」中验证原手机号后更换；原号码停用时请 联系客服。
团队版可以随时降级吗？
可以，降级在当前计费周期结束后生效，期间功能不受影响。
