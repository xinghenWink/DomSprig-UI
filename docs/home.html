快速开始

1引入

全量引入构建产物，或用 CLI 只复制需要的组件源码。

<link rel="stylesheet" href="dist/nova.css">
<script src="dist/nova.js"></script>

2使用

给原生元素加上类名或 data-nv-* 属性，动态插入的元素也会自动初始化。

<select data-nv-select data-search>…</select>
Nova.toast.success('已保存')

3定制

设计变量集中在 tokens.css；主题、主色与圆角可在运行时切换。

<html data-theme="dark">
:root { --nv-hue: 165; --nv-radius: 12px; }
